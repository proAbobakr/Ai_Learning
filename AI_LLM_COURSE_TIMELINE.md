## Time Management Tips

### 1. Pomodoro Technique
- 25 min focused work
- 5 min break
- Repeat 4x
- 15-30 min long break

### 2. Deep Work Blocks
- 2-4 hour uninterrupted sessions
- No notifications
- Single task focus
- Maximum learning

### 3. Spaced Repetition
- Review Day 1, Day 3, Day 7, Day 14
- Use flashcards (Anki)
- 15 min daily review

### 4. Active Recall
- Code without looking
- Explain concepts aloud
- Teach someone else
- Write blog posts
